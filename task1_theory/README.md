# 任务1：理论理解题

## 问题回答

### 1. "小陀螺"战术对传统自瞄算法的挑战

小陀螺战术通过机器人底盘高速旋转，给传统自瞄算法带来多重挑战：

**一、操作延迟与预测困难**
- 机器人存在多方面的操作延迟，需要通过观察对手机器人运动状态来预测运动趋势
- 小陀螺状态下云台和底盘分离，敌方底盘高速旋转，自瞄无法跟上旋转速度
- 云台运动滞后于装甲板运动，即使预瞄也会因提前量过多导致射击落空

**二、目标跟踪与稳定性问题**
- 敌方底盘不断旋转，装甲板在被锁定后快速消失在我方视野中
- 需要频繁切换识别不同装甲板，云台在切换中来回转动无法稳定
- 目标快速移动导致图像模糊，特征提取困难，命中率显著下降

### 2. 低曝光设置对灯条特征提取的优势

适当的降低相机曝光对灯条特征提取具有重要优势：

- **防止过曝**：保证灯条不会过曝而呈现白色，保持灯条的色彩特征
- **增强对比**：减少环境中其他光源的干扰，增强灯条与背景的对比度
- **优化处理**：使灯条在图像中更加突出，便于后续的二值化和轮廓提取处理
- **减少噪声**：降低环境光反射和其他噪声的影响，提高识别准确率和稳定性

### 3. Ubuntu相对于Windows的三个优势

**一、开发环境友好性**
- 在Linux系统下开发C++程序可以方便地配置各种第三方库和依赖
- 通过apt软件包管理器轻松安装各种软件和开发库（头文件、动态链接库等）
- 更好的命令行工具和脚本支持，提高开发效率

**二、系统性能优化**
- Linux系统的内核和上层系统比Windows更加精简
- 运行时占用的各类资源都要小于Windows，更充分地利用系统资源
- 最大程度压榨电脑性能，为视觉算法程序提供更好的运行环境

**三、生态支持完善**
- 对深度学习的支持比Windows更加友好和稳定
- 对各种设备驱动的支持更完善，特别是机器人相关硬件
- 丰富的开源工具链和社区支持，便于问题排查和技术交流

### 4. 图像分类与目标检测的区别

**图像分类（Image Classification）**
- 主要任务：只输出图像中物品的种类标签
- 输出结果：单一的类别标识（如"猫"、"狗"、"汽车"）
- 不提供位置信息：并不标记每个物品在图像中的具体位置

**目标检测（Object Detection）**
- 双重任务：既要识别出物品的种类，还要定位物品的位置
- 输出结果：类别标签+边界框（bounding box）坐标
- 提供空间信息：用矩形框架标记出目标在图像中的精确位置
- 应用场景：需要知道"是什么"和"在哪里"的视觉任务

### 5. 图像畸变与相机标定

**图像畸变（Distortion）**
- 畸变类型：主要分为切向畸变和径向畸变（桶型畸变）
- 产生原因：由于相机镜头本身的光学性质和制造工艺问题
- 物理机制：光线在经过镜头时改变了原有的空间传播路径
- 表现结果：图像发生形变，直线变弯曲，距离比例失真

**相机标定（Calibration）的必要性**
- 消除失真：通过标定算法校正畸变，还原图像中物体的真实位置
- 精确测量：为后续的几何测量、三维重建提供准确的图像基础
- 获取参数：确定相机的内参（焦距、主点）和外参（位置姿态）
- 应用前提：任何基于视觉的精确测量都必须先进行相机标定

### 6. solvePnP函数的作用与理解

**主要作用**
- solvePnP函数通过相机中出现的已知物体的3D点坐标和其在图像中的2D投影点
- 计算相机的相对于物体的位姿，包括旋转矩阵和平移向量

**PnP问题理解**
- PnP（Perspective-n-Point）是计算机视觉中的经典问题
- 通过n个3D世界点与2D图像点的对应关系，求解相机的外参数
- 在RoboMaster中用于估计机器人相对于敌方目标的精确位姿
- 为后续的瞄准和打击提供准确的空间位置信息

### 7. 卡尔曼滤波器的作用

**为什么使用卡尔曼滤波器**
- 单纯使用两帧之间的位置差计算速度会受噪声严重影响
- 无法有效处理运动过程中的不确定性和测量误差
- 需要一种能够融合多源信息的优化估计算法

**主要解决的问题**
- **噪声处理**：通过对系统状态进行建模，有效平滑观测噪声
- **数据融合**：融合多帧观测数据，提高估计的鲁棒性和准确性
- **状态估计**：对目标的位置、速度、加速度等状态进行最优估计
- **预测能力**：准确预测未来时刻的目标位置，弥补系统延迟

**在机器人运动预测中的应用**
- 提升跟踪效果：通过状态预测提高目标跟踪的稳定性
- 补偿延迟：弥补图像处理、通信、控制等环节的时间延迟
- 提高命中率：通过准确的运动预测提升打击效果
- 多传感器融合：整合视觉、IMU等多种传感器信息
